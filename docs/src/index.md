# YouTube Transcript Fetcher

**YouTube Transcript Fetcher** is an [Obsidian](https://obsidian.md) plugin that fetches a YouTube video's transcript and embeds it in your notes, with optional AI cleanup and a choice of output formats.

This manual covers everything the plugin can do. If you just want to get going, start with [Installation](installation.md) and [Getting Started](getting-started.md).

## What it does

- Fetches the transcript for any YouTube video that has captions, with clickable timestamps linking back to the exact moment in the video
- Optionally cleans up the transcript with an LLM (OpenAI, Gemini, Claude, or any OpenAI-compatible endpoint such as OpenRouter or Ollama) and can generate a short summary
- Saves the result as Markdown, PDF, and/or SRT — pick one or several formats per request
- Organizes output with saved directories, cover notes for PDF/SRT attachments, channel tags, and video metadata in frontmatter
- Works from an open note, from a default directory, or straight from your clipboard
